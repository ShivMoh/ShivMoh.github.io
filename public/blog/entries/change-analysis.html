Remote Sensing and Waves?

Okay so here's my layman's understanding of remote sensing. There's two types, passive and active. Passive just observes using energy around us, like sunlight and heat. They depend on external energy sources. Examples includes cameras and radiometres. Active remote sensing on the other hand is well...drum roll...active, as in it actively produces its own energy for its mystical magical remote sensing purposes. Examples include LiDAR (which I've recently been diving into coincidently...but more on that some other time) and radar. Other than that, there's the general concept that waves have different lenghts (highschool physics stuff) and surface properties have different reflective / absorptive properties meaning how these waves interact with the on ground vegetation, land types and what nots is important. And that for now, is all i really understand.

How Cloud Free Mosaic's are formed

Now this here was something I genuinely never thought about until this very point but from retrospect, of course this has to be the case. So guess what, even with satellite imagery, most of the time there's lots and lots of cloud blocking the view of given areas. In the case of Guyana that almost always seems to be the case. So as we can see from the above...Guyana's can hardly be seen :). So how does one see the beautiful Guyana when viewing 'satellite' imagery in most online maps? Simple, you "lie". So basically how it works is that over a given time period, your prase through satellite imagery data and extract the little bits that don't have cloud coverage and you do that over a long enough period until you get a stitched together image of what is a 'cloud free' version of you area of interest.

function maskS2clouds(image) {
  var opaque = image.select('MSK_CLASSI_OPAQUE');
  var cirrus = image.select('MSK_CLASSI_CIRRUS');
  var mask = opaque.eq(0).and(cirrus.eq(0));
  return image.updateMask(mask).divide(10000);
}
So the code above more or less just selects the individual bits that correspond the features labeled as clouds. If you go through the documentation here, you'll see more details. But basically, the people that made the dataset already created identifiers so we can select it from the region. So all the above function does really is select the areas that don't have those clouds, that is where the values equal 0 (meaning no clouds!) 

// just a helper function for creating a colection
function create_collection(date_start, date_end) {
  var sentinelCollection = ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED')
  .filterBounds(guyana) // filter to guyana
  .filterDate(date_start, date_end) // filter between the set date periods
  .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 80)) // filter based on acceptable level of cloudiness
  .map(maskS2clouds);
  return sentinelCollection;
  
}

// create a mosaic based on median values
function create_mosaic(collection, area) {
  var median_mosaic = collection.median();
  return median_mosaic.clip(area);
}
So the first function in the snipper above just creates and image collection based on a bunch of filters. The important one is the filter(ee.Filter.lt('CLOUD_PIXEL_PERCENTAGE', 80)) which sets the threshold of what level of 'cloudiness' is acceptable to us. Making the percentage lower in our case, would mean we tolerate less cloudiness. And the second function is just creating the mosaic based on our collection and clipping it to our defined area.
